# Mod Pembangun
1. Tetapkan peranan akaun anda (FIREBASE_SETUP.md). Log masuk dalam talian.
2. Menu -> **Pentadbir** -> (jika ditetapkan di pelayan) masukkan kod pengesahan -> **Masuk editor dunia**.
3. Editor: anak panah gerak kursor (Kamera = putar 90 darjah; seret kawasan kanan atas untuk orbit); Naik/Turun untuk ketinggian; **Katalog** pilih objek -> **Letak**; **Pilih** objek berdekatan kursor -> anak panah alih, Putar (15 darjah), Besar/Kecil, Padam; Asal/Ulang; Langkah (1/5/10).
4. **Simpan** = draf baharu di pelayan (BELUM live). **Versi** -> Muat / Terbit atau Pulih (perlu pengesahan; versi terbit menjadi dunia LIVE untuk semua pemain). **Eksport/Import** guna papan klip.
5. **Masa** & **Cuaca** disimpan bersama draf. **Ke kursor** = teleport pemain.
6. Mod Terbang/tembus dinding dan teleport koordinat: panel Pentadbir.
Had: 3000 objek, +-240 unit, skala 0.2-6. Pelayan menolak objek tidak dikenali/di luar sempadan. Pemain biasa tidak boleh mengubah aset dunia awam (pelayan menolak). Tiada kata laluan atau kunci perkhidmatan dalam APK.
Belum: editor rupa bumi, penjana litar/had laju, pilih berbilang, perlanggaran dioptimum.
