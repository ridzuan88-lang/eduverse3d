# Mod luar talian
Tiada internet diperlukan. Simpanan: `user://eduverse_save.json` (profil, avatar, XP, syiling, baris gilir sync). Kuiz melawan Robot AI (3 tahap). Selepas log masuk dalam talian, `Sync.gd` menghantar baris gilir; transaksi diterima/pendua/ditolak dikeluarkan daripada baris gilir; kegagalan rangkaian mengekalkannya untuk cubaan seterusnya.
Catatan: satu profil setempat bagi setiap peranti; token sesi disimpan dalam fail simpanan app (storan persendirian app).
